## Goal

## What to inspect

- Repository config files such as `telecode.json`, package config, environment examples, and config modules
- Provider and model registry code
- Agent defaults, model selection, fallback rules, and permission or location-specific overrides
- Any docs or tests that describe routing behavior

1. Current routing/config summary
2. The effective input and output of the relevant configuration path

4. A proposed change plan before editing anything substantial

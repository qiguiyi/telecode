ชุดโครงการชุมชนที่สร้างขึ้นบน TeleCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ TeleCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-telecode](https://github.com/awesome-telecode/awesome-telecode) และ [telecode.cafe](https://telecode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
